# Step 21 — 开始转发时可选物理麦
范围：删除路由页中间的「混入麦克风」卡片，把混音开关放到状态栏开始/停止旁；设置页仍负责选择物理麦设备。

完成：
- 物理麦未在设置页选择时，状态栏「混入物理麦」禁用。
- 设置了物理麦后，勾选才会在 `AudioEngine::start` 时挂载麦源。
- 不勾选时即使设置页有物理麦，也不会混入。
- 选择保存到 `RouteConfig.mix_mic`。
- 路由页不再重复显示物理麦卡片。

scripts\\build-dev.cmd build
