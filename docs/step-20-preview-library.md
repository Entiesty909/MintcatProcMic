# Step 20 — 预览与音频库真实接入
范围：完成音频库分类树、原生本地文件添加、右侧音频列表、双击解码播放到 SFX ring；预览输出总线与多进程/多输出尚未在本阶段实现。

完成：
- 音频库左侧分类树：全部、未分类及配置中的分类。
- Windows 原生文件选择器添加本地音频。
- 音频条目保存到 `AppConfig.audio_entries`。
- 右侧音频列表支持搜索、选中、双击播放。
- 双击通过 `AudioReader` 读取 WAV/Media Foundation 文件，并发送 `SfxCommand::Play`。
- 停止按钮发送 `StopAll`。
- 播放时按键仍是设置页全局配置，不属于音频项。

怎么跑：
```bat
scripts\\build-dev.cmd build
```

实测：
- Debug 构建通过。
- 原生文件选择器相关 Windows API 编译通过。
- 分类树与音频列表 Slint 页面编译通过。

未完成：

- 右键新建/重命名/删除分类树节点。
- 多进程输入、多输出设备。
