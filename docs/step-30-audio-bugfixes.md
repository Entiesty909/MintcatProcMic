# Step 30 — 长音频切换、分类菜单与导入校验
范围：修复长音频切换时旧解码任务继续运行造成的卡顿；修复分类右键回调的借用冲突闪退；把新建、重命名、删除集中到分类右键菜单；导入前限制扩展名并验证 WAV/MF 音轨；修复本机试听源忙循环导致的播放异常，并在音频库播放时确保打开本机默认播放设备作为监听。未改变进程路由、输出设备选择和播放时按键配置。
改动文件：
- `src/audio/decode.rs`：增加可取消完整解码与导入前媒体校验。
- `src/audio/wav.rs`：增加只读 WAV 头的轻量探测，避免导入长 WAV 时先完整加载。
- `src/audio/buffer.rs`：增加试听环缓冲清空。
- `src/audio/preview.rs`：试听源按 50 ms 音频块节流，切换前清空积压。
- `src/ui_bridge.rs`：切换/停止取消旧解码，立即停止旧声音；修复分类回调 RefCell 重入；导入前校验；文件选择器去掉“所有文件”兜底；播放时确保本机默认播放设备监听已创建。
- `ui/pages/player.slint`、`ui/main.slint`：分类新建、重命名、删除移入右键菜单，并移除分类卡片顶部操作按钮。
怎么跑：
- `scripts\\build-dev.cmd build`
- `target\\debug\\mintcat-proc-mic.exe --list-devices`
- 无参数启动 UI，在音频库中右键分类，测试新建/重命名/删除；添加不支持文件确认不会进入列表；双击播放确认本机默认播放设备有声，再切换长音频。
实测：
- 2026-09-24，Windows x64：构建成功，仅有已有 dead-code 警告。
- `--list-devices` 成功列出 Realtek、VB-CABLE、Steam Streaming 等设备。
- UI 进程启动并持续运行，验证后停止。
- 未在当前自动化环境中执行真实扬声器听感、右键鼠标操作和长音频硬件播放；这些仍需桌面手动验收。
下一步：
